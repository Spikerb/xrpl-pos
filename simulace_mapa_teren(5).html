Nadmořská výška a zastínění terénem se počítají ze skutečných výškových dat veřejného Open-Elevation API (dvanáct směrů, vzdálenosti 0,5-8 km) - vyžaduje internetové připojení. Tento veřejný server bývá občas pomalý nebo dočasně nedostupný; pokud analýza selže, zkuste to znovu za chvíli, nebo zadejte výšku a horizont ručně. Typ podloží se z mapy nedetekuje automaticky. Sluneční geometrie je počítána přesnou astronomickou formulí. Model neuvažuje dlouhovlnné záření, vypařování ani oblačnost.
